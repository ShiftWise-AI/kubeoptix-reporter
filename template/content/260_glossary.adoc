.Terminologia geral
[cols="3,8",options=header]
|===
|Termos | Definição

// Termo
|RHC
// Definição
|Red Hat Consulting. Capaz de fornecer engenharia para criação de soluções e análises remotamente ou presencial (on site).


// Termo
|GSS (também conhecido como CEE)
// Definição
|Red Hat Global Support Services (“suporte”) também conhecido como 
“Customer Experience and Engagement”. Capaz de resolver bugs, problemas 
de configuração e orientar RFEs.


// Termo
|RFE
// Definição
|Request for Enhancement. Essas são solicitações dos clientes ou da engenharia Red Hat para novas funcionalidades (features) ou comportamentos do produto. Geralmente rastreado internamente como um BZ.

// Termo
|BZ
// Definição
|Bugzilla. Este contexto refere-se à instância específica do Bugzilla controlada pela Red Hat para rastrear bugs, RFEs e liberar informações. Além disso, pode se referir ao bug com um número específico do Bugzilla quando fornecido a um artigo ou a outro BZ.

// Termo
|Upstream
// Definição
|Refere-se ao final do processo de desenvolvimento de software de código-fonte aberto e relacionado a colaboração da comunidade open source, documentação e testes.

// Termo
|Downstream
// Definição
|Refere-se ao final do processo de desenvolvimento de software open source (binário assinado) implementável e "produtificado" relacionado a uma errata contratada, artefatos de suporte baseados em eventos, engenharia de produto e documentação específica do produto.

// Termo
|Case
// Definição
|Support Case, RH Case, Red Hat support case, solicitado e priorizado pelo cliente e, em seguida, respondido diretamente pela equipe da GSS. Esse número de caso é diferente de um número de bug da BZ (a maioria dos casos de suporte da RH não tem uma BZ correspondente e vice-versa).

// Termo
|TAM
// Definição
|Technical Account Manager. Um gerente de recursos designado ao site do cliente pela GSS que possui o conhecimento específico do cliente, tem conhecimento das demandas/problemas e conduz para soluções.

// Termo
|KB
// Definição
|Knowledge Base article, um breve e específico guia de instruções disponível no portal do cliente.


// Termo
|RHEL
// Definição
|Red Hat Enterprise Linux


// Termo
|RPM
// Definição
|RPM Package Manager (um acrônimo recursivo)


// Termo
|DNS
// Definição
|Domain Name Service


// Termo
|FQDN
// Definição
|Fully Qualified Domain Name

|===
