////
Objetivo
-------
Forneça um local para capturar requisitos e detalhes à medida que são
identificados durante um compromisso.

Requerimento
------
Forneça uma descrição de requisito de alto nível para cada requisito.

Detalhes
------
Forneça qualquer detalhe adicional relacionado aos critérios de sucesso para o requisito.

Para obter mais informações, consulte: Melhores Práticas de CER - https://source.redhat.com/groups/public/gcs_asociates_success_enablement/global_enablement/content_strategy_programs/engagementjournalstandardization/consulting_engagement_report_cer_wiki/cer_best_practices 
e Entrega do CER - https://source.redhat.com/groups/public/gcs_asociates_success_enablement/global_enablement/content_strategy_programs/engagementjournalstandardization/consulting_engagement_report_cer_wiki/delivering_the_cer 

Exemplo
------

|===
|Requisito
|Detalhes

// Requerimento
| aplicativo olá mundo

// Detalhes
a|
- o aplicativo deve carregar

// Requerimento
| Automação da implantação de VM

// Detalhes
a|
- Implantação de VM automatizada com endereço IP pré-configurado
- Implantação de VM automatizada com acesso de usuário pré-configurado
