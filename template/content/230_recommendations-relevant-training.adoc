== Red Hat Satellite Technical Overview (RH053)

Red Hat® Satellite é uma plataforma escalável usada para gerenciar patch (pacotes e repositórios), provisionamento e gerenciamento de assinaturas (subscription) de sua infraestrutura da Red Hat. Aprenda sobre os principais recursos do Red Hat Satellite e veja como o Satellite pode ajudar a atender às suas necessidades de negócios.

Através de vídeos on-line sob demanda, você aprenderá sobre:

- Gerenciamento de patches e software.
- Gerenciamento de assinaturas usando o Red Hat Satellite.
- Provisionamento usando o Red Hat Satellite.
- Gerenciamento de configuração usando o Red Hat Satellite.
- Integração do Red Hat Satellite com Red Hat Ansible® Automation e o Red Hat Insights.

Para obter detalhes completos, ou para se inscrever:
https://www.redhat.com/en/services/training/rh053-red-hat-satellite-technical-overview

== Red Hat Satellite 6 Administration (RH403)

Red Hat Satellite 6 Administration (RH403) é um curso prático com laboratório que explora os conceitos e métodos necessários para o sucesso do gerenciamento em larga escala dos sistemas Red Hat® Enterprise Linux®. Os participantes do curso aprenderão como instalar o Red Hat Satellite 6 em um servidor e carregar pacotes de software.

Este curso é baseado no Red Hat Enterprise Linux 7 e no Red Hat Satellite 6.

Os alunos usarão o Red Hat Satellite para gerenciar o ciclo de vida de desenvolvimento de software de um host registrado e sua configuração, e aprenderão como provisionar hosts integrados ao Puppet (Software de gerenciamento de configuração).

Resumo do conteúdo do curso:

- Instalação do Red Hat Satellite 6.
- Red Hat Network Organizações, locais, usuários e funções.
- Gerenciamento de software com Red Hat Satellite environments e Content Views.
- Criação de pacotes RPM personalizados.
- Use o Red Hat Satellite para configurar hosts com o Puppet.
- Provisionamento de hosts com gerenciamento integrado de software e configuração.
- Implementação de Metal como serviço (MaaS) com Satellite discovery e provisioning de hosts não provisionados.

Para obter detalhes completos, ou para se inscrever:
https://www.redhat.com/en/services/training/rh403-red-hat-satellite-6-administration
