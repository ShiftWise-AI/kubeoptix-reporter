Propósito
-------
Esta seção deve duplicar e consolidar todos os links para recursos externos
contidos em outras partes deste documento. A intenção é criar um único
ponto de referência para todos os recursos externos.

A partir desta versão, o processo de consolidação de links externos é manual.
Em algum momento, esse processo pode estar automatizado. (Se você se encarregar de
automatizar o processo, compartilhe-o com o CER WG para que possa ser incorporado
no processo!)

Exemplo
------
Link com as últimas versões de drivers do UCS VIC:
https://www.cisco.com/c/en/us/td/docs/unified_computing/ucs/sw/vic_drivers/install/Linux/b_Cisco_VIC_Drivers_for_Linux_Installation_Guide.html

Exemplo de REST API para iniciar(subir) uma VM no RHV
https://access.redhat.com/documentation/en-us/red_hat_virtualization/4.3/html/rest_api_guide/documents-004_quick_start_example#start_the_virtual_machine
